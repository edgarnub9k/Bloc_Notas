# 📝 Bloc de Notas

> Una aplicación web de bloc de notas ligera, minimalista y funcional construida para organizar ideas de forma rápida y eficiente.

---

## 🚀 Tecnologías Utilizadas

Este proyecto fue desarrollado utilizando tecnologías web estándar y un entorno ligero en el backend:

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)

* **Backend / Entorno:** Node.js, Express (`package.json`)
